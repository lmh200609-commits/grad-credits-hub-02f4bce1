## 问题诊断

侧边栏当前虽然有 active 样式（淡色背景 + 3px 左侧色条），但存在以下定位不清晰的问题：

1. **嵌套路由不高亮**：所有菜单都用了 `end` 严格匹配。当进入 `/applications/:id`（审核详情）、`/admin/users/students/:id`（学生详情）等子页面时，侧边栏所有项都不高亮，用户完全失去定位。
2. **active 视觉太弱**：`bg-primary/10` 在浅色背景上对比度低，扫一眼很难分辨当前在哪。
3. **折叠态无定位**：侧边栏折叠成图标条后，左侧色条仍在但图标本身无任何强对比，更难分辨。
4. **顶部 header 无定位信息**：header 只显示"学分认证系统"，没有当前页面名/面包屑。

## 解决方案

### 1. 侧边栏菜单：智能 active 匹配 + 强化视觉

- 移除 `NavLink` 的 `end` 严格匹配，改为基于 `useLocation` 自定义匹配函数：
  - 完全相等命中
  - 当前路径以菜单 `url + "/"` 开头时也命中（覆盖详情页等子路由）
  - `/` 工作台仅在完全相等时命中（避免吞掉所有路径）
- 特殊映射：`/applications/:id`（审核详情）命中"待审核 / 全部审核"；`/admin/users/students/:id` 命中"学生管理"等。
- 强化 active 样式：
  - 展开态：实心 `bg-primary text-primary-foreground` + 图标加粗，与未选中项形成强对比
  - 左侧色条加粗到 4px，并且全高
  - 折叠态：选中图标用 `bg-primary text-primary-foreground` 圆角块包裹，确保一眼可见
- 当前菜单项加 `aria-current="page"`，无障碍友好

### 2. 顶部 header 显示当前页面名

- 在 header 加一行"当前页面"指示：`学分认证系统 / 当前页标题`
- 通过 `useLocation` + 路由→标题映射表（与侧边栏菜单复用同一份配置）实时显示
- 详情页显示父级名称（如"全部审核 / 详情"）
- 移动端只显示当前页标题，桌面端显示完整路径

### 3. 配置集中化

- 把三个角色的菜单配置 + 子路由匹配规则提取到 `src/lib/navigation.ts`，导出 `getNavItems(roles)`、`getActiveItem(pathname, items)`、`getPageTitle(pathname, items)`。
- AppLayout 的 sidebar 与 header 都从这里读，保证一致。

## 需要修改/新增的文件

- 新增 `src/lib/navigation.ts`：菜单配置 + 路径匹配工具
- 修改 `src/components/AppLayout.tsx`：
  - sidebar 部分用新匹配逻辑，强化展开/折叠态 active 样式
  - header 部分加当前页标题显示
